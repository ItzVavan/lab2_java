# Задание 1. Точки
## Задача 1.1 (Класс Point1)
### Текст задачи
Создайте сущность Точка, расположенную на двумерной плоскости, которая описывается двумя координатами X и Y[cite: 6]. Класс должен возвращать текстовое представление вида "{X;Y}"[cite: 6].

### Алгоритм решения
1. Создать класс `Point1` с приватными полями `x` и `y` типа `int`[cite: 6].
2. Реализовать конструктор по умолчанию (устанавливающий координаты в 0, 0) и конструктор с двумя параметрами[cite: 6].
3. Переопределить метод `toString()` для формирования строки вида `"{X;Y}"`[cite: 6].

## Задача 4.1 (Класс Point4_1)
### Текст задачи
Измените сущность Точка из задачи 1.1[cite: 6]. В соответствии с новыми требованиями создать объект Точки можно только путем указания обеих координат X и Y[cite: 6].

### Алгоритм решения
1. Создать класс `Point4_1`[cite: 6].
2. Удалить конструктор по умолчанию, оставив единственный конструктор `Point4_1(int x, int y)`, что исключает создание объекта без явного задания координат[cite: 6].
3. Добавить геттеры, сеттеры и метод `toString()`[cite: 6].

# Задание 2. Линии
## Задача 2.1 (Класс Line2_1)
### Текст задачи
Создайте сущность Линия, которая состоит из двух точек: начала и конца (используются точки из задачи 1.1)[cite: 6].

### Алгоритм решения
1. Создать класс `Line2_1` с двумя полями `start` и `end` типа `Point1`[cite: 6].
2. Реализовать конструктор, принимающий два объекта `Point1`[cite: 6].
3. При изменении параметров начальной или конечной точки первой линии изменения автоматически отражаются на всех связанных линиях, так как они ссылаются на один и тот же объект в памяти[cite: 6].

## Задача 4.2 (Класс Line4_2)
### Текст задачи
Измените сущность Линия из задачи 2.1[cite: 6]. Новые требования включают:
1. Создание Линии с указанием готовых объектов Точек из задачи 4.1 (Point4_1)[cite: 6].
2. Создание Линии с указанием координат начала и конца в виде четырех чисел (x1, y1, x2, y2)[cite: 6].

### Алгоритм решения
1. Создать класс `Line4_2` с полями типа `Point4_1`[cite: 6].
2. Реализовать перегрузку конструкторов:
   - `Line4_2(Point4_1 start, Point4_1 end)` — инициализация готовыми точками[cite: 6].
   - `Line4_2(int x1, int y1, int x2, int y2)` — автоматическое создание объектов `Point4_1` прямо внутри конструктора[cite: 6].

## Задача 5.3 (Класс Line5_3)
### Текст задачи
Измените сущность Линия из задачи 4.2[cite: 6]. Добавьте ей возможность возвращать по запросу пользователя расстояние между точками начала и конца (в виде целого числа)[cite: 6].

### Алгоритм решения
1. Создать класс `Line5_3`, наследующий класс `Line4_2` с помощью ключевого слова `extends`[cite: 6].
2. В конструкторах использовать `super(...)` для передачи параметров родительскому классу[cite: 6].
3. Добавить метод `getLength()`, вычисляющий Евклидово расстояние по формуле $\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$ с округлением до целого числа с помощью `Math.round()`[cite: 6].

# Задание 3. Студенты
## Задача 3.1 (Класс Student)
### Текст задачи
Создайте сущность Студент (Имя и массив оценок)[cite: 6].
1. Создать студента Васю с оценками: 3, 4, 5[cite: 6].
2. Создать студента Петю и присвоить ему массив оценок Васи[cite: 6].
3. Изменить первую оценку Пети на 5, вывести состояние обоих студентов и объяснить результат[cite: 6].
4. Создать студента Андрея с копией оценок Васи так, чтобы изменения оценок Васи не влияли на Андрея[cite: 6].

### Алгоритм решения
1. Создать класс `Student` с полями `name` (`String`) и `grades` (`int[]`)[cite: 6].
2. Реализовать метод `setGrades()` для поверхностного копирования (передача ссылки на массив)[cite: 6].
3. Реализовать метод `setGradesCopy()`, создающий независимый массив через метод `.clone()` (глубокое копирование)[cite: 6].
4. Продемонстрировать в `Main`, что при изменении оценок Пети меняются оценки Васи (так как ссылка одна), а при изменении оценок Васи оценки Андрея остаются прежними[cite: 6].
