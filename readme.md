# Лабораторная работа №2 (Вариант №1)

## Описание проекта
Данный проект представляет собой реализацию Варианта 1 лабораторной работы №2 по Java без использования пакетов (`package`). 

Программа демонстрирует ключевые концепции объектно-ориентированного программирования (ООП):
- **Инкапсуляция:** ограничение прямого доступа к полям классов с помощью модификатора `private` и работа через геттеры/сеттеры[cite: 6].
- **Перегрузка и ограничение конструкторов:** создание объектов различными способами и контроль обязательных параметров[cite: 6].
- **Работа со ссылочными типами данных:** разница между поверхностным (передача ссылки) и глубоким (создание независимой копии) копированием объектов и массивов[cite: 6].
- **Наследование:** расширение функционала существующих классов с помощью ключевых слов `extends` и `super`[cite: 6].

# Раздел 1. Задание 1.1 и 4.1 (Точки)

## Задача 1.1 — Точка координат (Класс `Point1`)
### Текст задачи
Создайте сущность Точка, расположенную на двумерной плоскости, которая описывается двумя координатами X и Y[cite: 6]. Класс должен возвращать текстовое представление вида `"{X;Y}"`[cite: 6].

### Реализация и комментарии
1. Класс `Point1` содержит поля `x` и `y` типа `int` с модификатором `private`[cite: 6].
2. Реализованы конструктор по умолчанию (устанавливает координаты в `0;0`) и конструктор с параметрами[cite: 6].
3. Переопределен метод `toString()`, возвращающий строку с текстовым комментарием о координатах в формате `"{X;Y}"`[cite: 6].

## Задача 4.1 — Создаем Точку (Класс `Point4_1`)
### Текст задачи
Измените сущность Точка из задачи 1.1[cite: 6]. В соответствии с новыми требованиями создать объект Точки можно **только путем указания обеих координат X и Y**[cite: 6].

### Реализация и комментарии
1. В классе `Point4_1` удален конструктор по умолчанию[cite: 6].
2. Оставлен **единственный конструктор** `Point4_1(int x, int y)`, что гарантирует невозможность создания объекта без явной инициализации обеих координат[cite: 6].

# Раздел 2. Задание 2.1, 4.2 и 5.3 (Линии)

## Задача 2.1 — Линия (Класс `Line2_1`)
### Текст задачи
Создайте сущность Линия, которая состоит из двух точек: начала и конца (используются точки из задачи 1.1)[cite: 6].

### Реализация и комментарии
1. Класс `Line2_1` содержит два поля: `start` и `end` типа `Point1`[cite: 6].
2. **Демонстрация работы ссылок:** Если у первой линии изменить координаты начальной точки через сеттер, эти изменения автоматически отражаются на всех линиях, которые ссылаются на тот же объект `Point1` в памяти[cite: 6].

## Задача 4.2 — Создаем Линию (Класс `Line4_2`)
### Текст задачи
Измените сущность Линия из задачи 2.1[cite: 6]. Новые требования включают:
1. Создание Линии с указанием готовых объектов Точек из задачи 4.1 (`Point4_1`)[cite: 6].
2. Создание Линии с указанием координат начала и конца в виде четырех чисел (`x1, y1, x2, y2`)[cite: 6].

### Реализация и комментарии
1. Поля `start` и `end` переведены на тип `Point4_1`[cite: 6].
2. Реализована **перегрузка конструкторов**:
   - `Line4_2(Point4_1 start, Point4_1 end)`[cite: 6]
   - `Line4_2(int x1, int y1, int x2, int y2)` (внутри автоматически создаются объекты `Point4_1`)[cite: 6].

## Задача 5.3 — Длина Линии (Класс `Line5_3`)
### Текст задачи
Измените сущность Линия из задачи 4.2[cite: 6]. Добавьте ей возможность возвращать по запросу пользователя расстояние между точками начала и конца (в виде целого числа)[cite: 6].

### Реализация и комментарии
1. Класс `Line5_3` **наследует** класс `Line4_2` (`public class Line5_3 extends Line4_2`)[cite: 6].
2. Конструкторы передают параметры родителю через `super(...)`[cite: 6].
3. Добавлен метод `getLength()`, рассчитывающий Евклидово расстояние по формуле:
   $$\text{Length} = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$
4. Результат округляется до целого числа методом `Math.round()`[cite: 6].

# Раздел 3. Задание 3.1 (Студент)

## Задача 3.1 — Студент (Класс `Student`)
### Текст задачи
Создайте сущность Студент (Имя и массив оценок)[cite: 6]. 
1. Создать студента Васю с оценками: 3, 4, 5[cite: 6].
2. Создать студента Петю и присвоить ему массив оценок Васи[cite: 6].
3. Изменить первую оценку Пети на 5, вывести состояние обоих студентов и **объяснить результат**[cite: 6].
4. Создать студента Андрея с копией оценок Васи так, чтобы изменения оценок Васи не влияли на Андрея[cite: 6].

### Реализация и комментарии
1. В классе `Student` созданы два метода передачи оценок:
   - `setGrades(int[] grades)` — **поверхностное копирование** (передача ссылки)[cite: 6].
   - `setGradesCopy(int[] grades)` — **глубокое копирование** через метод `.clone()`[cite: 6].
2. **Объяснение результатов (комментарий к заданию):**
   - **Петя и Вася:** Так как `petya.setGrades(vasya.getGrades())` копирует только ссылку на массив, оба студента указывают на один и тот же участок памяти. Изменение оценки Пети меняет и оценку Васи[cite: 6].
   - **Андрей и Вася:** Метод `.clone()` создает независимый дубликат массива в куче (Heap), благодаря чему изменения оценок Васи больше не затрагивают Андрея[cite: 6].
