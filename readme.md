# Задание 1
## Задача 1 (Точка координат)
### Текст задачи
Создайте сущность Точка, расположенную на двумерной плоскости, которая описывается:
• Координата Х: число
• Координата Y: число
• Может возвращать текстовое представление вида “{X;Y}”
Необходимо создать три точки с разными координатами и вывести на экран их текстовое представление.

### Алгоритм решения
1. Создать класс `Point` с приватными целочисленными полями `x` и `y`.
2. Реализовать конструктор, который принимает обе координаты `x` и `y` для инициализации объекта (согласно доработкам из задания 4.1).
3. Добавить геттеры и сеттеры для полей координат.
4. Переопределить метод `toString()`, возвращающий строку формата `"{X;Y}"`.
5. В главном методе `main` создать 3 объекта класса `Point` и вывести их текстовое представление с помощью `System.out.println()`.

## Задача 2 (Человек с именем)
### Текст задачи
Объедините сущности Человек из задачи 1.2 и Имя из задачи 1.3 таким образом, чтобы имя человека задавалось с использованием сущности 1.3, а не строки.

• Человека с Именем Маяковский Владимир и ростом 189

3. Реализовать конструктор `Person(Name name, int height)` и метод `toString()`, форматирующий вывод в виде `"Имя, рост: height"`.

## Задача 3 (Человек с родителем)
### Текст задачи
Измените сущность Человек из задачи 2.2 добавив ему возможность задавать третий параметр: Отец, где Отец — это тоже Человек. При приведении человека к строковой форме необходимо проверить параметры имени, и в зависимости от ситуации выполнить одно из следующих действий:
• Если у данного человека нет фамилии, и есть отец, у которого фамилия задана, то фамилию необходимо сделать такой же как у отца.
• Если у данного человека нет отчества, а у отца есть имя, то необходимо задать отчество как имя отца с добавлением суффикса “ович”.
Затем необходимо выполнить следующие задачи:
1. Создать людей: Чудова Ивана, Чудова Петра, Бориса
2. Сделать Ивана отцом Петра, а Петра отцом Бориса
3. Вывести на экран строковое представление всех троих людей.

### Алгоритм решения
1. Добавить в класс `Person` поле `father` типа `Person`.
2. Написать внутренний приватный метод `updateNameByFather()`, который проверяет:
   - Если у текущего человека не задана фамилия в объекте `Name`, но у отца фамилия есть — присвоить человеку фамилию отца.
   - Если у текущего человека не задано отчество, но у отца есть личное имя — сформировать отчество путем добавления суффикса `"ович"` к имени отца.
3. Вызывать `updateNameByFather()` в конструкторе `Person` и в сеттере `setFather()`.
4. В методе `main` создать объекты Ивана, Петра и Бориса, связать их отношениями отцовства и вывести результаты на экран.

# Задание 3
## Задача 1 (Студент)
### Текст задачи
Создайте сущность Студент, которая описывается:
• Имя: строка
• Оценки: массив целых чисел.
• Может возвращать текстовое представление вида “Имя: [оценка1, оценка2,…,оценкаN]”
Необходимо выполнить следующие задачи:
1. Создать студента Васю с оценками: 3,4,5.
2. Создать студента Петю и скопировать оценки Васи, присвоив содержимое поля с оценками Васи полю с оценками Пети.
3. Заменить первую оценку Пети на число 5. Вывести на экран строковое представление Васи и Пети. Объяснить результат.
4. Создать студента Андрея и скопировать ему оценки Васи так, чтобы изменение оценок Васи не влияло на Андрея.

### Алгоритм решения
1. Создать класс `Student` с полями `name` (`String`) и `grades` (`int[]`).
2. Добавить сеттеры `setGrades(int[] grades)` (поверхностное копирование по ссылке) и `setGradesCopy(int[] grades)` (создание глубокой копии через `.clone()`).
3. Переопределить `toString()` с использованием `Arrays.toString(grades)`.
4. В методе `main` проиллюстрировать передачу ссылок (изменение оценок Пети меняет оценки Васи) и независимое глубокое копирование массива для Андрея.

## Задача 2 (Создаем Линию)
### Текст задачи
Измените сущность Линия из задачи 2.1. Новые требования включают:
• Создание Линии возможно с указанием Точки начала и Точки конца (Точки из задачи 4.1)
• Создание Линии возможно с указанием координат начала и конца как четырех чисел (x1,y1,x2,y2)
Создайте линии со следующими характеристиками:
1. Линия 1 с началом в т. {1;3} и концом в {23;8}.
2. Линия 2, горизонтальная, на высоте 10, от точки 5 до точки 25.
3. Линия 3 которая начинается всегда там же где начинается линия 1, и заканчивается всегда там же, где заканчивается линия 2.

### Алгоритм решения
1. Создать класс `Line` с полями `start` и `end` типа `Point`.
2. Реализовать два конструктора: `Line(Point start, Point end)` и `Line(int x1, int y1, int x2, int y2)`.
3. Реализовать метод `toString()`, выводящий текстовое представление отрезка.
4. В методе `main` создать Линию 1 и Линию 2.
5. Для создания Линии 3 передать в конструктор ссылки `l1.getStart()` и `l2.getEnd()`, тем самым обеспечив связывание объектов.

## Задача 3 (Длина Линии)
### Текст задачи
Измените сущность Линия из задачи 4.2. Добавьте ей возможность возвращать по запросу пользователя расстояние между точками начала и конца (в виде целого числа). Создайте линию из точки {1;1} в точку {10;15} и выведите на экран её длину.

### Алгоритм решения
1. В класс `Line` добавить метод `getLength()`, возвращающий значение типа `int`.
2. Рассчитать расстояние между точками по формуле Евклидова расстояния: $\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$.
3. Округлить результат до целого с помощью `Math.round()` и привести к типу `int`.
4. В методе `main` создать объект `Line` с координатами (1,1) и (10,15), вызвать метод `getLength()` и вывести результат в консоль.
